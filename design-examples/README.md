# Примеры дизайна ChickenHouse

Откройте в браузере один из пяти вариантов: `index.html` — текущий светлый вариант, `workshop.html` — тёплая светлая мастерская, `control.html` — тёмный диспетчерский пульт, `blue-panel.html` — светлая панель с синей навигацией, `briefing.html` — оперативная сводка с верхним меню и строками систем. Содержание и демонстрационные взаимодействия одинаковы. Это автономный макет: показания и авария на обзоре вымышлены, сетевые запросы отсутствуют, настройки и управление отключены.

Меню содержит обзор, шесть существующих разделов автоматики, все регистры и настройки. Обзор показывает краткие сведения о климате, вентиляции, лазе, кормлении, освещении и авариях; ссылки ведут к подробностям. На подробных страницах показаны группы и подписи текущего интерфейса, календарь, состояние кормушек и расписание кормления. Прочерк означает, что данные недоступны в примере.

Страница регистров показывает 144 существующих адреса: 0–101 и 110–151. Адреса 102–109 в карте отсутствуют. Поиск работает локально. У R0–R4 раскрываются 16 подписанных флагов с неизвестным состоянием. У R100 доступны 16 демонстрационных переключателей: они меняют только локальное значение, не посылают команд и не воспроизводят подтверждение или сброс контроллером. Подписи взяты из интерфейса прошивки, но сами по себе не подтверждают смысл регистров; значения не считываются и запись отключена.

На телефонах и планшетах карточки перестраиваются в одну колонку, меню прокручивается по горизонтали, таблицы при необходимости тоже прокручиваются. Визуальную проверку на реальных устройствах нужно провести отдельно.

При возможной реализации необходимо сохранить существующие маршруты, поведение регистров, права доступа, AP, сценарий первоначальной установки пароля и восстановление доступа. Достоверность единиц, масштаба и трактовки сигналов следует сверить с владельцем и спецификацией.

Флаги регистров раскрываются под строкой регистра на всю ширину: на телефоне — одной колонкой, на широком экране — двумя.

Дополнительный вариант `sunny.html` — солнечная панель с логотипом `logo-sunny-1.png`. Он использует те же демонстрационные данные и экраны.
