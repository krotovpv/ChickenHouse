# ChickenHouse

Прошивка модуля ESP32 Dev для системы управления курятником. В сети Modbus устройство работает как Slave-шлюз: предоставляет ведущему контроллеру карту Holding-регистров для обмена данными. Оно также даёт пользователю веб-панель, передаёт данные в MQTT, предоставляет HTTP API для SCADA-систем и отправляет аварийные уведомления через Telegram.

Ведущий контроллер Modbus — самодельное устройство; его марка и модель пока не известны. Пользователь управляет курятником через веб-интерфейс ESP32, а внешние SCADA-системы подключаются через MQTT и HTTP API.

## Критичное требование

Владелец должен иметь возможность подключиться к веб-интерфейсу ESP32. Изменения, затрагивающие Wi-Fi, точку доступа, DNS captive portal, HTTP-маршруты, авторизацию или пользовательские сессии, не должны лишать пользователя этого доступа.

> Назначение оборудования, полная семантика регистров и фактическая схема подключения ещё требуют подтверждения. См. [вопросы владельцу](docs/open-questions.md); не используйте непроверенные сведения как инструкцию по подключению реального оборудования.

## Сборка

Проект хранится на GitHub. Для сборки и прошивки используется расширение PlatformIO в Visual Studio Code с окружением `esp32dev`; сейчас устройство подключено к COM6. Номер порта может измениться при другом подключении. Команда сборки:

```sh
pio run -e esp32dev
```

Зависимости PlatformIO заданы в `platformio.ini`. После неудачного обновления необходимо перепрошить ESP32 через USB с помощью PlatformIO.

## Первый запуск и настройка

Код поднимает точку доступа Wi-Fi с именем `ChickenHous` и запускает веб-сервер. При наличии сохранённых параметров устройство также подключается к роутеру. Текущие значения точки доступа заданы прямо в коде; их следует считать настройками разработки, пока владелец не подтвердит иное.

Для прямого подключения выберите сеть `ChickenHous`. Телефон может предложить открыть страницу входа в сеть: нажмите уведомление или дождитесь появления окна панели. Если предложение не появилось, откройте в браузере `http://192.168.4.1` (адрес точки выводится также в последовательный порт). Если телефон сообщает об отсутствии интернета, разрешите ему оставаться подключённым к этой сети.

Если ESP32 и телефон или компьютер подключены к одному домашнему роутеру, откройте `http://chickenhouse.local/`. Это имя использует mDNS: его поддержка зависит от устройства, сети и настроек роутера; при необходимости используйте локальный IP ESP32 из настроек панели или последовательного порта. Если в одной сети несколько ESP32 с этой прошивкой, одинаковое имя может мешать выбору нужного устройства. После открытия панели можно добавить ссылку на главный экран телефона через меню браузера; названия пунктов зависят от телефона.

Настройки Wi-Fi, MQTT и Telegram вводятся через веб-интерфейс и хранятся в NVS/Preferences на устройстве. При первом включении расширенного режима пароль администратора задаётся через точку доступа. Фактические адреса, эксплуатационные пароли, токены и другие секреты не следует публиковать в документации или коммитить в репозиторий.

## Команды ведущему контроллеру

Регистр 100 используется для передачи команд ведущему контроллеру: старший байт `0x01`, младший — код команды. Например, `0x0102` сбрасывает аварию датчика температуры, а команда `03` записывается как `0x0103`. После выполнения Master записывает `0x0000`. Подробности — в [карте регистров](docs/register-map.md).
