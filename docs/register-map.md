# Карта Modbus-регистров

## Статус

Исходный код объявляет Holding-регистры с адресами **0–101** и **110–151**. Все значения первоначально равны нулю. Их прикладная семантика в репозитории описана лишь частично. Этот документ не назначает регистрам смысл по косвенным догадкам.

Обозначения:

- **Неизвестно** — требуется первичная спецификация или подтверждение владельца.
- **Известно по коду** — код использует поле для конкретной логики, но это не обязательно полное описание назначения.

Статус регистра 100 подтверждён владельцем. Остальные подписи взяты из текущего текста уведомлений и являются только наблюдаемым поведением прошивки. Они не заменяют карту регистров управляющего контроллера.

## Регистр 100: панель команд

`R100` — 16-битное поле одноразовых команд от ESP32 к Modbus Master. Источником установки бита может быть веб-интерфейс, MQTT или HTTP API. После считывания Master выполняет команду и сам сбрасывает соответствующий бит. ESP32 не подтверждает выполнение отдельно: сброс бита является наблюдаемым признаком обработки.

Неизвестны и должны быть определены в первичной спецификации: значение каждого бита, допустимость нескольких одновременных команд, время ожидания, обработка неудачного выполнения и действия при перезапуске ESP32 до обработки команды.

- Для числовых значений: тип (signed/unsigned), масштаб, единицы, порядок слов/байтов для составных значений.
- Какие регистры разрешено менять через Modbus, MQTT и веб-панель? Есть ли команды с ограничениями по безопасности?
