# Карта Modbus-регистров

## Статус

Исходный код объявляет Holding-регистры с адресами **0–101** и **110–151**. Все значения первоначально равны нулю.

Обозначения:

- **Неизвестно** — требуется первичная спецификация или подтверждение владельца.
- **Известно по коду** — код использует поле для конкретной логики, но это не обязательно полное описание назначения.

## Адресные диапазоны

| Диапазон | Количество | Начальное значение | Примечание |
|---|---:|---:|---|
| 0–101 | 102 | 0 | Объявлены в `src/registers.cpp` |
| 102–109 | 8 | — | В текущей карте отсутствуют |
| 110–151 | 42 | 0 | Объявлены в `src/registers.cpp` |

## Интервалы времени Modbus Master

| Диапазон регситров | Интервал времени | Чтение/Запись |
| 0-23 | 1 секунда | Запись |
| 24-71 | 1 минута | Запись |
| 72-145 | 1 раз в сутки | Запись |
| 100-101 | 1 секунда | Чтение |

### Таблица команд для 100 регистра

| Код команды (два байта) | Команда по документу |
|---|---|
| 0x00FF | Сброс устройства |
| 0x0101 | Включить проветривание, включая оба вентилятора |
| 0x0102 | Обнулить аварию датчика температуры |
| 0x0103 | Открыть лаз и зафиксировать |
| 0x0104 | Закрыть лаз и зафиксировать |
| 0x0105 / 0106 | Зафиксировать лаз / Расфиксировать лаз |
| 0x0107 | Обнулить ошибки датчика загазованности |
| 0x0108 / 0x0109 / 0x010A / 0x010B | Выдать порцию корма кормушкой К1 / К2 / К3 / К4 соответственно |
